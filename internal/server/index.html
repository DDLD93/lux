lux-api

HTTP wrapper around the lux video download library. Submit a URL, poll for progress, then download the result.

Open UI → Swagger UI OpenAPI spec List jobs (JSON) Health

Quickstart

Base URL: {{.ServerURL}}

1. Start a download job

curl -s -X POST {{.ServerURL}}/jobs \
  -H 'content-type: application/json' \
  -d '{"url":"https://www.youtube.com/watch?v=dQw4w9WgXcQ"}'

Response: {"id":"<uuid>"} — keep the id for polling.

2. Poll progress (HTTP polling)

curl -s {{.ServerURL}}/jobs/<id>
# { "state": "downloading", "percent": 42.5, "bytes_downloaded": ..., "bytes_total": ... }

States: queued → extracting → downloading → done | failed | canceled.

3. Download the resulting file

curl -OJ {{.ServerURL}}/jobs/<id>/file

Metadata only (no download)

curl -s -X POST {{.ServerURL}}/extract \
  -H 'content-type: application/json' \
  -d '{"url":"<page-url>"}'

Cancel a job

curl -X DELETE {{.ServerURL}}/jobs/<id>

Endpoints

MethodPathPurpose
POST/jobsStart a download job
GET/jobsList all jobs
GET/jobs/{id}Poll job status / progress
DELETE/jobs/{id}Cancel job + remove partials
GET/jobs/{id}/fileDownload finished file
POST/extractSynchronous metadata
GET/healthzLiveness

Notes

  • Job state is in-memory — restarting the container forgets jobs.
  • Progress is derived by polling the on-disk job directory every 500ms.
  • Cancellation is best-effort: lux's downloader does not accept a context.
